# ÂnimA — Art Tattoo

Protótipo por Crisora. Site estático com cenas controladas pelo scroll, galeria filtrável e formulário de orçamento com resumo para copiar e enviar pelo Instagram.

## Executar

```sh
python3 -m http.server 8080
```

O site está na raiz do repositório. Para GitHub Pages, escolha a branch main e a pasta / (root).

Imagens de tatuagens são conceptuais, geradas para a proposta; não representam trabalhos do estúdio. Logo e ilustração recuperadas dos materiais fornecidos. Portefólio real, estilos, contactos e condições sujeitos à validação do estúdio. Formulário não envia nem guarda dados; prepara o texto no dispositivo.

Fontes Bodoni Moda e Urbanist sob OFL, licenças em assets.
